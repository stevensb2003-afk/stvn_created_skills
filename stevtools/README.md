# 🧰 Utilidades Personales (`/stevtool-*`)

Herramientas operativas reutilizables orientadas a hardware, dispositivos y automatizaciones locales.

## 📦 Instalación de esta Categoría

```bash
# Desde la raíz del repositorio stvn_created_skills:
./install.sh --category stevtools
```

## 🗂️ Skills Incluidas

* [`stevtool-cleanyourtv`](./stevtool-cleanyourtv/) — Gestor aislado multi-televisor de **CleanYourTV** para Android TV / Google TV. Incluye CLI Python (`scripts/tv_manager.py`), documentación de la edición personal (Wi-Fi/Bluetooth/Timer/Ambient), parche (`resources/cleanyourtv-personal.patch`) y archivos override del launcher (`resources/personal-overrides/`).
