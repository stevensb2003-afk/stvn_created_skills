# ☁️ Cloud, Deploy, OAuth, SEO & Seguridad Web (`cloud-deploy-and-security/`)

Skills de **código, infraestructura y Web Engineering** para aprovisionar proyectos GCP/Firebase, gobernar despliegues SemVer sin pantallas blancas, verificar Google OAuth y dominios, auditar SEO/GEO + cabeceras Grado `A+` y optimizar compresión HTTP.

## 📦 Instalación de esta Categoría

```bash
./install.sh --category cloud-deploy-and-security
```
