# 🚀 Creative Agency OS & Video Skills Hub

Colección maestra de skills personalizadas para **Google Antigravity**, optimizadas para producción audiovisual, automatización de contenidos para creadores y agencias creativas.

---

## 📦 Instalación Rápida en Antigravity

Para instalar todas estas skills en tu entorno local de Antigravity (macOS o Linux):

```bash
mkdir -p ~/.gemini/config/skills
git clone https://github.com/stevensb2003-afk/stvn_created_skills.git ~/.gemini/config/skills/stvn_created_skills
```

*(Si ya lo tienes clonado, para actualizar simplemente ejecuta `git pull` dentro de esa carpeta).*

## 🛠️ Skills Incluidas

### 1. Sistema Operativo y Setup
* **`create_agency_master_guide`**: Instalador inteligente del Creative Agency OS. Autodetecta el sistema operativo, instala dependencias (`FFmpeg`, `ImageMagick`, `Potrace`, `Whisper`, `Remotion`), monta la arquitectura de carpetas y configura los pipelines.

### 2. Video y Edición para Creadores
* **`talking-head-recut`**: Empaquetado y rotulación para videos a cámara (Reels, TikToks, YouTube). Títulos cinéticos, lower-thirds y tarjetas sincronizadas.
* **`faceless-explainer`**: Convierte texto o guiones en videos explicativos con motion graphics y tipografía dinámica.
* **`music-to-video`**: Edición *beat-synced* al ritmo de la música.
* **`captions-overlay`** & **`embedded-captions`**: Generación y formateo de subtítulos animados y dinámicos.
* **`changelog-video`**: Convierte notas o changelogs en videos de producto de alta calidad.
* **`product-launch-video`** & **`pr-to-video`**: Generación de videos de lanzamiento y walkthroughs.
* **`general-video`** & **`slideshow`**: Composición libre y presentaciones dinámicas.

### 3. Suite HyperFrames (Motion Graphics en Código)
* **`hyperframes`** / **`hyperframes-cli`**: CLI y motor de desarrollo para renderizado en MP4.
* **`hyperframes-core`**: Contrato y estructura de composiciones.
* **`hyperframes-animation`** & **`hyperframes-keyframes`**: Curvas de animación y movimientos de cámara.
* **`hyperframes-creative`**: Dirección de arte, paletas y tipografía.
* **`hyperframes-registry`**: Catálogo de bloques y componentes.
* **`remotion-to-hyperframes`**: Migración y adaptación entre frameworks.

### 4. Marca e Identidad
* **`brandkit`**: Creación de tableros de identidad visual, paletas de color y sistemas de marca.
* **`oversized-cursor`**: Efectos de cursor estilizados para tutoriales y demos.
