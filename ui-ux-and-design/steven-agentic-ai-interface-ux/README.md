# `steven-agentic-ai-interface-ux`

Arquitectura UX para **interfaces de chat, copilotos e IA agéntica**, convirtiendo la conversación en un espacio de trabajo verificable, fluido y sin saltos visuales.

---

## 🧩 Los 7 Patrones Esenciales

1. **Empty State (*Recognition over Recall*):** `3–4` prompt chips accionables específicos del dominio en vez de pantallas vacías.
2. **Atmósfera cálida y granulada:** Film Grain `6%–8%` anti-bandas, sin degradados plástico-neón.
3. **Labor Illusion calibrada:** pasos intermedios reales con tiempos en `tabular-nums`, colapsables al finalizar.
4. **Citas verificables *Origin-Aware* (`[1]`, `[2]`):** popovers que nacen desde el chip citado con extracto y enlace real.
5. **Streaming Zero-CLS + Smart Auto-Scroll:** `CLS < 0.05` y pausa automática del scroll si el usuario sube a leer (`"↓ Jump to latest"`).
6. **Brushing & Linking bidireccional:** hover sincronizado entre entidades del texto y barras/series de gráficos.
7. **Human-in-the-Loop (HITL) + Undo optimista (`0ms`):** tarjeta previa de confirmación (`Not now` / `Approve`) antes de mutaciones irreversibles.
