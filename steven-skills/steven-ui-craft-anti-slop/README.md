# `steven-ui-craft-anti-slop`

Auditoría y reconstrucción visual para erradicar estética genérica de IA ("AI slop") y reemplazarla por geometría óptica exacta, color perceptual **`OKLCH`**, microtipografía calibrada, radios concéntricos (`inner_radius = max(0px, outer_radius - padding)`), sombras ambientales teñidas y superficies táctiles.

---

## 📂 Contenido de esta Carpeta

* [`SKILL.md`](./SKILL.md) — 20 reglas `DON'T` / `DO`, tabla de tokens exactos (measure `60ch–65ch`, `tabular-nums`, targets `44×44px`), tarjetas Neo-Brutalistas y checklist de auditoría.
* [`references/surfaces-and-backgrounds-catalog.md`](./references/surfaces-and-backgrounds-catalog.md) — Catálogo completo de **22 fórmulas CSS/SVG** de superficies no planas (*Paper*, *Speckled graphite*, *Fluted glass*, *Halftone*, *Blueprint grids*, etc.).

```bash
./install.sh --skill steven-ui-craft-anti-slop
```
