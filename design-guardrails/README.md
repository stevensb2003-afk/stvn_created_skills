# 🛡️ Guardrails de Diseño UI/UX (`design-guardrails/`)

Reglas estrictas para impedir estética genérica de IA ("vibecoding") y exigir estándares de diseño de producción en código frontend.

## 📦 Instalación de esta Categoría

```bash
# Desde la raíz del repositorio stvn_created_skills:
./install.sh --category design-guardrails
```

## 🗂️ Skills Incluidas

* [`anti-vibecoding-design-guardrails`](./anti-vibecoding-design-guardrails/) — 20 anti-patrones prohibidos y reemplazos obligatorios, presets tipográficos por vertical, reglas regex de linting y lista negra de copywriting genérico.
